📖 PDF Studio Pro 사용 방법

1
다중 PDF 파일 업로드

[PDF 파일 추가] 버튼을 누르거나 드래그하여 파일1, 파일2 등 원하는 만큼의 PDF 문서를 업로드합니다.

2
원하는 페이지 클릭 및 선택

업로드된 각 PDF 파일 탭에서 필요한 페이지 썸네일을 클릭하여 선택합니다. Shift 키를 누르고 클릭하면 연속된 페이지 범위를 한 번에 선택할 수 있습니다.

3
드래그 & 드롭으로 새 편집창에 결합

선택한 페이지를 마우스로 끌어서 오른쪽 [새로운 PDF 편집창]으로 놓으세요. 먼저 옮긴 페이지 뒤로 다음 파일의 페이지들이 자동으로 순서대로 착 이어붙습니다.

4
제목 및 글쓰기 편집

편집창에 모인 각 페이지의 [제목/글쓰기] 버튼을 클릭하여 페이지 상단 제목, 메모, 날짜 등을 원하는 위치에 자유롭게 작성하고 스타일을 지정합니다.

5
새 PDF 다운로드

우측 상단의 [새 PDF 생성 및 다운로드] 버튼을 누르면 모든 페이지와 작성한 제목이 선명하게 결합된 새 PDF 파일이 즉시 컴퓨터에 저장됩니다.
