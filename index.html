📖 PDF Studio Pro 사용 방법

1
다중 PDF 파일 업로드

[PDF 파일 추가] 버튼을 누르거나 드래그하여 파일1, 파일2 등 원하는 만큼의 PDF 문서를 업로드합니다.

2
원하는 페이지 클릭 및 선택

업로드된 각 PDF 파일 탭에서 필요한 페이지 썸네일을 클릭하여 선택합니다. Shift 키를 누르고 클릭하면 연속된 페이지 범위를 한 번에 선택할 수 있습니다.

3
[이동 ▶] 버튼 클릭 또는 드래그로 편집창에 이동

좌측에서 원하는 페이지를 클릭하여 선택한 뒤 가운데/하단의 [이동 ▶] 버튼을 클릭하거나 마우스로 끌어다 놓으세요. 휴대폰에서도 터치로 간편하게 이동됩니다.

4
캡처 화면 바로 붙여넣기 (Ctrl+V)

화면 캡처(Win+Shift+S, PrintScreen 등) 후 우측 편집창에서 Ctrl+V를 누르거나 [📋 캡처 붙여넣기] 버튼을 누르면 캡처 이미지가 새 페이지로 즉시 추가됩니다.

5
700% 돋보기 확대 및 제목/글쓰기 편집

편집창 각 페이지의 🔍 돋보기 버튼을 누르면 700% 초대형 고화질로 확대되며, [글쓰기] 버튼으로 제목·메모·지우개 편집 후 새 PDF로 저장할 수 있습니다.
